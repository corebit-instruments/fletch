# Fletch issue tracker

Engineering Tasks live in
[`corebit-instruments/fletch`](https://github.com/corebit-instruments/fletch/issues)
and belong to the organization's
[Modulo Project #1](https://github.com/orgs/corebit-instruments/projects/1).
`agentic.toml` owns the CLI mapping and default Status for new ETs.

Load `agentic:engineering-tasks` for tracker work. Its
[shared skill](https://github.com/corebit-instruments/agentic/blob/main/plugins/agentic/skills/workflows/engineering-tasks/SKILL.md)
owns record templates, lifecycle, and CLI commands. The fallback source paths
are in [AGENTS.md](../../AGENTS.md).
